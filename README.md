Muse Bags - Mijn Webshop
Waar gaat dit project over?
Dit is mijn project voor het vak Static Web. Ik heb een webshop gemaakt voor handtassen. De webshop heet Muse Bags. Je kan de producten bekijken op de homepage en als je op een product klikt, zie je meer details over dat product.

Er is ook een admin gedeelte waar de beheerder van de webshop kan inloggen om de producten te bekijken en nieuwe producten toe te voegen.

Hoe ben ik begonnen?
Ik begon met het kijken van de video's van de docent op Canvas. Die video's hielpen me echt om te snappen hoe ik moest beginnen. Ik keek hoe de docent een website opbouwde en probeerde dat na te doen. Ik las ook de PowerPoints die erbij stonden, maar de video's waren voor mij het duidelijkst.

Toen ik iets niet begreep, keek ik de video's opnieuw. Soms moest ik een stukje meerdere keren bekijken voor ik het snapte. De video's hebben me heel goed geholpen om te zien hoe je code moet schrijven en hoe je structuur aanbrengt in je website.

Daarna maakte ik een plan. Ik moest een webshop maken en ik koos voor handtassen omdat ik dat leuk vind. Ik verzon de naam "Muse Bags".

Hoe heb ik AI gebruikt?
Ik heb AI (DeepSeek) gebruikt om me te helpen met de code. Soms wist ik niet hoe ik iets moest doen in CSS of HTML. Dan vroeg ik aan de AI hoe ik het moest aanpakken. De AI gaf me dan een voorbeeld en legde uit waarom het zo moest. Dat hielp me echt om de code beter te begrijpen.

Soms was ik een functie vergeten die ik eerder had gezien. Dan vroeg ik aan de AI: "Kan je mij die functie terug uitleggen?" De AI legde het dan opnieuw uit en gaf een voorbeeld. Zo kon ik verder werken zonder dat ik alles opnieuw moest zoeken in de cursus.

Ik heb niet zomaar de code van de AI gekopieerd. Ik keek eerst naar wat de AI voorstelde en probeerde het dan zelf te schrijven. Als ik iets niet snapte, vroeg ik waarom het zo moest. Zo heb ik veel geleerd.

Wat heb ik gemaakt?

De homepage
Op de homepage staat de naam van de winkel en een welkomsttekst. Daaronder staan alle producten met een foto, de naam en de prijs. Je kan op "Bekijk" klikken om meer te zien over dat product.

De productdetail pagina's
Voor elk product heb ik een aparte pagina gemaakt. Daar staat meer informatie zoals een beschrijving, de prijs, de kleur en de afmetingen. De foto's zijn daar ook groter.

Het admin gedeelte
De admin heeft een eigen stuk van de website. Je moet eerst inloggen op de login pagina. Daarna zie je een dashboard met een tabel van alle producten. Je kan ook producten toevoegen via een formulier.

Het winkelmandje
Er is ook een winkelmandje pagina. Die is nog leeg omdat we in Static Web geen echte winkelmandje kunnen maken zonder JavaScript.

Welke kleuren heb ik gebruikt?
Ik heb bruine en crèmekleuren gebruikt omdat dat mooi past bij handtassen. De hoofdkleuren zijn:

Bruin voor de header en knoppen
Crème wit voor de achtergrond
Donkerbruin voor de footer

Welke lettertypes?
Ik heb Google Fonts gebruikt. Voor de titels heb ik een mooi lettertype gekozen en voor de gewone tekst een ander lettertype.

Wat heb ik geleerd?
Ik heb geleerd hoe je een website maakt met HTML en CSS. Ik snap nu beter hoe je een homepage maakt, hoe je navigatie werkt, en hoe je een admin gedeelte maakt met een inlogpagina en een dashboard. De video's van de docent hebben me hier heel goed bij geholpen.

Hoe zet je de website op?
Je moet de bestanden openen in Visual Studio Code en dan Live Server gebruiken. De homepage is index.html. Voor de admin ga je naar de map admin en open je login.html.

Wat was moeilijk?
Het moeilijkste vond ik om alles netjes te krijgen met CSS. Soms stond iets niet op de juiste plek en moest ik lang zoeken waarom. Ook het admin gedeelte was lastig omdat ik daar een andere stijl moest gebruiken.

Wat ben ik trots op?
Ik ben trots dat ik een werkende website heb gemaakt met meerdere pagina's en een admin gedeelte. Ik kan nu aan de docent laten zien wat ik kan.
